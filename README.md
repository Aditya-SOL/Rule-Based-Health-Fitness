# FitGuide AI — Rule-Based Health & Fitness Guide

This is an AI mini-project: a rule-based expert system that gives general diet-planning and fitness guidance for healthy adults.

## Project structure

- `src/` — Python application code
- `tests/` — checks that verify the rules
- `data/` — sample, non-personal data used for testing
- `web/` — future simple website files
- `docs/` — project report notes and diagrams

## Safety boundary

FitGuide AI provides general educational guidance only. It does not diagnose conditions or provide medical diet advice.

## Run the website

From this folder, run:

```powershell
python web/server.py
```

Then open `http://127.0.0.1:8000` in a web browser.

## Run the tests

```powershell
python tests/run_tests.py
```
